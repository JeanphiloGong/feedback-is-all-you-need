# Research references

This directory records the sources used to frame the feedback hypothesis and
compare it with existing work on scaling, reinforcement, self-correction, and
continual learning.

- `source-records.json` stores source URLs, bibliographic metadata, and
  abstracts for the initial literature set.
- `title-precedent.json` records an existing 2023 paper with the title
  **“Feedback is all you need: from ChatGPT to autonomous driving”**
  ([DOI: 10.1007/s11432-023-3740-x](https://doi.org/10.1007/s11432-023-3740-x)).
  The manuscript must cite and clearly distinguish this prior use of the title.
- `attention-manifest.json` records the source and checksum for the original
  *Attention Is All You Need* paper.

PDF files are local research inputs and are excluded from this public
repository. The manifests preserve stable source URLs and retrieval metadata so
that a future researcher can reproduce the reference set.
